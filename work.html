⬇️ Part 2: The Fork (if / else) 🛤️

The if statement checks a condition. If it is True, the indented code runs. If not, it skips to the else.

age = 15
if age >= 18:
    print("Welcome.")
else:
    print("Too young.")
⬇️ Part 3: Multiple Paths (elif) 🚦

The Milestone Checker

When you have more than two paths, use elif (short for else if) to check multiple conditions in order.

# Get the age and convert it to an integer
age = int(input("How old are you? "))

# Python checks these from top to bottom
if age < 16:
    # This block runs if age is 15 or less
    print("You can't drive yet.")
elif age < 18:
    # This block runs for ages 16 and 17
    print("You can't vote yet!")
elif age < 21:
    # This block runs for ages 18, 19, and 20
    print("You can't drink yet!")
elif age < 65:
    # This block handles ages 21 through 64
    print("You can't retire yet!")
    print("Are you counting the years?")
else:
    # This is the catch-all for age 65 and older
    print("Where would you like to retire to?")

Important Note: Python checks these from top to bottom. As soon as it finds a True statement, it runs that block and ignores the rest. This is why we check the youngest ages first!

🤔 Quick Logic Challenge

If a user enters 17, they are technically younger than 18, 21, and 63. Based on the top-down rule, why does only the "vote" message appear?

⬇️ Part 4: Pattern Matching with Match/Case 🔀

When you need to compare a single variable against a series of discrete values, Python uses the match/case statement (introduced in Python 3.10+) instead of a traditional switch statement.

"""
Python switch/case demo.

Python uses match/case (Python 3.10+) instead of a traditional switch statement.
"""

# ℹ️ Ask the user for a month name.
user_month = input("Enter a month name: ")

# ℹ️ match compares the value in parentheses to each case below.
# 💡 .lower() changes text to lowercase, so "January" and "january" both work.
# 🦗 Common bug: case statements must be indented under match.
match user_month.lower():
    case "january":
        print("New Year's Day and Martin Luther King Jr. Day")
    case "february":
        print("Presidents Day")
    case "march":
        print("St. Patrick's Day")
    case "april":
        print("Earth Day")
    case "may":
        print("Memorial Day")
    case "june":
        print("Juneteenth")
    case "july":
        print("Independence Day")
    case "august":
        print("No federal holiday")
    case "september":
        print("Labor Day")
    case "october":
        print("Halloween")
    case "november":
        print("Thanksgiving")
    case "december":
        print("Christmas Day")
    # ℹ️ _ means "anything else". It is the default case.
    case _:
        print("Please enter a full month name.")
⬇️ Part 5: When to Use Match/Case vs. Elif ⚖️

Choosing between a match/case statement and an if/elif/else chain depends on the complexity of your evaluation criteria:

  • Use match/case when: You are comparing a single variable or expression against a series of discrete, exact values or data patterns (such as menu choices, command strings, status codes, or structural data types). It keeps multi-way discrete value checks cleaner and more readable.
  • Use if/elif/else when: Your conditions involve ranges of values (e.g., numeric thresholds like age < 16), independent boolean expressions, or multiple different variables evaluated together in complex logical comparisons.

📝 Assignment: The Buffet Calculator (Match/Case & Days)

Create a new buffet program from scratch that uses match/case and user input for the day of the week.

⚠️ Before you begin: This assignment requires Python 3.10 or newer. Review Parts 1 through 5 before writing your program.

Step 1: Set up

Create a new file named buffet.py. Add this header docstring to the top of your file, then complete the numbered requirements below.

"""
-----------------------------------------------------------------------
ASSIGNMENT: 3B - The Buffet Calculator (Daily Specials)
DATE: [Insert Date]

-----------------------------------------------------------------------
"""

Requirements

  1. Ask the user for the day of the week. Use .lower() with the day input.
  2. Use a match/case statement to set the child price per year.
    • Tuesday: Set child_price_per_year to $0.50.
    • Sunday: Set child_price_per_year to $1.00 and print a notice that drinks are free.
    • Use the default case (case _) for every other day. Set child_price_per_year to $1.00.
    • The free-drinks notice does not add or subtract anything from the total price.
  3. Ask the user for their age and convert it to an integer.
  4. Calculate the base price using if/elif/else.
    • Under 1: FREE ($0.00)
    • Ages 1 to 12: Multiply the age by child_price_per_year.
    • Ages 13 to 64: $16.95 (Standard Adult)
    • Age 65 and older: $12.95 (Senior Discount)
    • Age 12 is a child price; age 13 is an adult price.
  5. Print the final price formatted as currency and display any applicable daily special notices.
  6. You may assume the user enters a valid full day name and a whole-number age.

Step 2: Build It in This Order

  1. Ask for the day of the week and store it in a variable.
  2. Use match/case to set child_price_per_year. Use $0.50 for Tuesday. Use $1.00 for Sunday and every other day; on Sunday, also print the free-drinks notice. Use case _ for every day that is not Tuesday or Sunday.
  3. Set child_price_per_year before calculating a price so Python knows which child rate to use.
  4. Ask for the user's age and convert it to an integer.
  5. Use one if/elif/else chain to determine the price from the age tiers.
  6. For ages 1 through 12, multiply the age by child_price_per_year. Age 13 uses the adult price.
  7. Print the final price as currency. The Sunday drinks message does not change that price.

💡 Use .lower() on the day input so capitalization (like "Tuesday" versus "tuesday") does not affect the result.

💡 Pro-Tips for Success:

  • Default Case: Use case _ for all days that are not Tuesday or Sunday.
  • Currency Formatting: To print a number as currency, use an f-string with a format specifier: print(f"Your total is ${price:.2f}"). The .2f forces two decimal places.
  • Test Your Logic: Tuesday and age 5 should result in a total of $2.50.
  • Indentation Check: Make sure your case statements are properly indented directly under your match statement!
